# Зависимости прототипа

Runtime Angular и компилятор обновлены до 21.2.26. Сборщик и CLI остаются на
21.0.0: более новые наборы при установке ссылались на отсутствующие в доступном
npm-реестре версии пакетов. Два Babel helper-пакета закреплены через overrides
по той же причине. Установленный набор фиксируется в package-lock.json.

Проверка npm audit обнаружила предупреждения в серверных и инструментальных
зависимостях. Это не версия для публичного развёртывания: перед ним необходимо
обновить зависимости и повторить аудит. Попытка установить рекомендованный
Express 4.22.3 остановилась из-за недоступного path-to-regexp 0.1.13.

Сервер по умолчанию доступен только через 127.0.0.1. Аккаунтов и модерации нет;
все участники комнаты видят её историю. Эта версия предназначена для локальной
разработки и проверки работы общего чата.

Повторная проверка: `npm audit` и `npm audit --omit=dev`. Не используйте
`npm audit fix --force` без проверки изменений API, сборки и тестов.

Rollup закреплён на 4.52.4: у 4.53.3 в доступном реестре отсутствовали некоторые платформенные пакеты. Проверка npm ci --dry-run прошла после замены.
