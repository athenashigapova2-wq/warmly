# Warmly

Студенческий мессенджер и сообщество университета.

Референс интерфейса: https://elite-uni-sphere-connect.base44.app

## Статус

Начальный репозиторий для разработки в VS Code. Приложение пока не реализовано.
Макеты задают направление дизайна, а не список уже работающих возможностей.

## Технологии

- Client: современный Angular + TypeScript.
- Server: Node.js + Express, REST API для регистрации и входа.
- Socket.IO: обмен сообщениями в реальном времени.
- MongoDB + Mongoose: пользователи, диалоги и история сообщений.

Сохраняем архитектуру MEAN из предоставленной статьи. Её примеры на AngularJS,
Express 4.14 и Socket.IO 1.4 не копируем как готовую основу: конкретные поддерживаемые
версии зависимостей зафиксируем при реализации первого рабочего среза.

## Структура

```text
Client/     Angular-приложение
Server/     Express API и Socket.IO
docs/       План MVP и архитектура
.vscode/    Рекомендации расширений и настройки редактора
```

## Работа в VS Code

Откройте эту папку через File → Open Folder. Node.js уже потребуется для следующего
этапа. Команды установки и запуска появятся вместе с реализацией; сейчас npm install
и npm start не предусмотрены.

План: [docs/MVP.md](docs/MVP.md). Архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
